# 验证指南

本文是可重复执行的检查清单，不是对当前部署的通过声明。兼容基线为 DSH `0.1.5-rc.1` / React 18；宿主升级后需重新测试。

## 隔离自动化测试

在本插件目录执行：

```sh
npm ci
npm run build
npm test
npm run test:browser
```

Chrome 默认位置及覆盖方法见 [README.md](README.md)。单元测试覆盖几何计算、reducer 和插件契约；浏览器 fixture 使用真实分支组件和模拟 slot 内容，不是实际 DSH 页面。

检查浏览器测试是否覆盖：

- 390×844px、320px 和 767px 手机宽度下主内容全宽全高，无顶部或左侧占位。
- 左侧 24×44px 贴边按钮、右箭头、顶部 88px 加安全区偏移。按钮仍会覆盖其小范围下方内容。
- 抽屉状态保留、背景 inert、焦点循环与恢复、原生式收起、嵌套设置与更高层 Portal。
- 768px 布局边界、1024px 原窄屏自动收起、桌面拖拽、右栏、标题、主题和卸载清理。

若测试生成 `artifacts/` 截图，它们仅代表隔离 fixture；不要当作真实部署验收截图发布。

## 实际部署验收

先按 [DEPLOYMENT.md](DEPLOYMENT.md) 校验 profile，再刷新现有已登录 GUI，记录自己的测试结果到仓库外的私有报告。不得通过导出凭据或绕过认证来验证。

- 在 390px / 320px 宽度及真实手机上检查全宽全高、横竖屏、安全区和贴边按钮位置。
- 展开侧栏不压窄中心内容；遮罩、原收起按钮和 Escape 可关闭抽屉。
- 会话列表、搜索与设置可使用；设置层不被抽屉遮挡，在设置内按 Escape 只关闭设置。
- 选择会话后本版不自动收起侧栏，可通过遮罩或原收起按钮关闭。
- 检查键盘焦点、明暗主题、桌面宽度拖拽与右栏行为。
- 确认仅启用一个布局模块；按回滚步骤确认能恢复官方布局。

通过隔离测试不保证每个第三方 overlay 或每台设备兼容；实际网络、浏览器和原生侧栏／设置行为必须单独验收。
